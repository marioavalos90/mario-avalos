# Calendario de turnos (demo)

Aplicación estática pensada como prueba rápida para Mario Ávalos. Permite pegar datos exportados desde Excel/CSV (Fecha, Colaborador, Turno) y genera un calendario mensual con colores por tipo de turno.

## Cómo usarla

1. Abre `index.html` en tu navegador (puedes usar una extensión de servidor local o simplemente arrastrar el archivo).
2. Pega el contenido de tu Excel en formato CSV en el cuadro de texto y presiona **Generar calendario**.
3. Opcional: marca la casilla para ocultar los nombres y ver solo los tipos de turno.
4. Usa el botón **Cargar ejemplo** si quieres ver un calendario de muestra de inmediato.

> Tip: si exportas tu hoja de Excel como `.csv`, puedes abrirlo con un editor de texto y copiar el contenido directamente.
